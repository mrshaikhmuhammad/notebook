# 📓 Notebook — Smart Notes Management Software

A Java-based notes management desktop application that provides an all-in-one platform for creating, organizing, summarizing, and managing notes efficiently.

Built by a 3-person team at Sukkur IBA University.

## 👩‍💻 Team
| Name | Role |
|---|---|
| Mahma Rani | Frontend (Java Swing) + Data Structures  |
| Shaikh Muhammad | Summarization API Integration+ JSON Integration |
| Shahzeb Ali | Summarization API & Backend + JSON Integration|

## 🛠️ Tech Stack
| Layer | Technology |
|---|---|
| Frontend | Java Swing |
| Backend | Java (OOP) |
| Data Structures | Java Collections & Custom DSA |
| Storage | JSON File Handling |
| Summarization | External API Integration |

## 🧠 OOP & DSA Concepts Used
- **Linked Lists / ArrayLists** — Managing ordered lists of notes
- **Encapsulation** — Data hiding across note objects
- **Inheritance** — Reusable base classes
- **Polymorphism** — Flexible note handling
- **Abstraction** — Clean interface-based design

## ✨ Features
### 📝 Notes Management
- Create new notes with title and content
- Organized note listing using data structures
- Notes stored and retrieved from JSON files

### 💾 Save Feature
- Save notes persistently to JSON
- Access saved notes anytime on restart

### 🤖 AI Summarization
- Summarize long notes using an external API
- Get quick summaries without reading full content

### 📂 Organization
- Browse and manage all notes in one place
- Clean and intuitive Java Swing interface

## 🗂️ Project Structure
Notebook/
├── src/
│   ├── frontend/     # Java Swing UI components
│   ├── notes/        # Note creation and management
│   ├── datastructures/ # Custom DSA for note lists
│   ├── storage/      # JSON read/write handling
│   └── summarization/ # API integration for summarization
├── lib/              # External libraries
└── README.md

## ⚙️ Getting Started
### Prerequisites
- Java JDK 8 or higher
- IntelliJ IDEA (recommended)

### Setup
1. Clone the repository
git clone https://github.com/mrshaikhmuhammad/notebook.git
2. Open in IntelliJ IDEA
3. Add required libraries from `/lib` folder to classpath
4. Run the main class
